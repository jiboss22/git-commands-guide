# Project Plan: A Guide to Git Commands

## Topic
A short how-to guide that teaches beginners the basic Git commands.

## Structure
1. Introduction – what Git is and why it is useful
2. Getting Started – git init, git clone, git status
3. Saving Changes – git add, git commit, git log
4. Branches – git branch, git checkout, git merge
5. Sharing with GitHub – git push, git pull
