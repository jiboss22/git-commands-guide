# Easy Git Commands Guide for Beginners

A beginner-friendly how-to guide covering the most common Git commands:
setting up a repository, saving changes, working with branches, and
sharing work on GitHub.

## Contents
- **PLAN.md** – the guide's topic, structure, and task list
- **guide.md** – the full guide

## How to Use This Guide
Open `guide.md` and read it from top to bottom. Each section explains a
group of Git commands and includes examples you can try in your own
terminal.

## How This Project Was Built
- Tasks were tracked with GitHub Issues and a Project Board
  (To Do, In Progress, Done).
- Each section was written on its own feature branch
  (`feature/introduction`, `feature/branches`).
- Every change was merged into `main` through a pull request linked to
  its issue, and branches were deleted after merging.

## Merge Conflict Resolution
To practice resolving conflicts, two branches changed the first line of
this README in different ways. After the first branch was merged, the
second pull request showed a conflict. I merged `main` into the second
branch, removed the conflict markers, combined both titles into one, and
pushed the fix before merging. See pull request #7 for details.
